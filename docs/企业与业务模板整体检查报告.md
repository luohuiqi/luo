## 3. 「企业模板」和「业务模板」对照

公开资产里**没有**以「企业模板」「业务模板」命名的两套目录，也没有企业级（组织/权限/租户）与业务级（课程/考试/直播）的分层。

按内容只能这样归：

| 应有分层 | 现状 | 缺口 |
| --- | --- | --- |
| **企业模板**（组织、角色、权限、审批、租户、数据归档规范、通用 SOP） | 不存在独立成套模板 | 无组织架构、无角色权限、无审批流、无多租户、无企业级主流程总图 |
| **业务模板**（课程、考试、直播、推送、专题、培训班） | 7 张泳道图，覆盖学习产品主模块 | 模块之间没有统一入口；命名、粒度、异常分支不一致；缺少认证闭环总图 |

一句话：现在看到的全是 **2018 年业务模块流程图**，企业层模板缺位，业务层模板也未整理成可复用的模板体系。

## 4. 逐模板检查

### 4.1 在线课程（使用最多）

覆盖：创建课程 → 授权/发布 → 学习范围 → 必修/选修 → 学习状态（未开始/学习中/已完成）→ 过程管理 → 数据归档。

问题：

- 标题是「在线课程」，图内又写「在线课程学习基本流程图」，对外名称不统一。
- 「影响未完成，学习新课件／新规则／新学分等」「全部影响」等节点过长，不像流程步骤，更像需求备注。
- 评审/评卷节点夹在学习流程里，和考试模板职责重叠。
- 没有失败、过期、下架后已学记录如何处理的完整分支。

### 4.2 考试流程图 / 移动考试流程图（重复度高）

PC 考试覆盖较全：创建考试、报名审核、组卷（随机/临时）、监考、强制交卷、阅卷、及格/补考、证书发放、数据归档。

移动考试额外有：切屏规则、答案显示/查看规则、证书配置、及格分数设置。

问题：

- 两张图是同一业务的端差异，没有抽公共「考试企业模板」+「移动差异业务模板」。
- 移动考试克隆仅 2 次，和 PC 考试 62 次差距大，说明复用关系没有讲清楚。
- 「普通考试基本流程图」作为节点名嵌在图里，像内部草稿标题漏出去了。

### 4.3 直播课程

覆盖：创建直播 → 安排教师/助教/学员 → 开启直播 → 监控 → 用户参与 → 数据归档。

问题：

- 文案错误：**「查案直播表」** 应为「查看直播表」。
- 「阅卷」「考试」「任务评审」出现在直播图中，边界不清。
- 「无法进入直播」只有结果，没有原因（未启动、权限、人数上限）和恢复路径。
- 「未启动 / 已启动」是状态，不是步骤，和流程节点混排。

### 4.4 学习推送

覆盖：创建推送 → 设置对象/内容 → 是否已注册 → 必修/选修变更 → 开始/继续学习 → 推送结果。

问题：

- 「性质无变化或原本是必修」「推送为必修，原为选修」是规则说明，不是流程节点。
- 失败后有「重新推送」，但没有失败原因、重试上限、对已学记录的影响。
- 与「在线课程」的必修/选修规则重复，没有引用关系。

### 4.5 学习专题

覆盖：创建专题 → 选择/配置模板 → 学习范围 → 发布/取消发布 → 学员学习 → 归档。

问题：

- 「配置模板 / 模板配置 / 选择模板」三个节点语义重复。
- 再次出现评卷、评审任务，专题和图中的考试职责搅在一起。
- 「不可学习」缺少前置条件（未发布、无权限、过期）。

### 4.6 培训管理基本流程图（企业侧最接近，但不可复用）

覆盖：创建/导入计划 → 资源审核 → 开班 → 报名 → 班务（签到、任务、调研、评估）→ 结项结算。

问题：

- **不允许克隆**，作为模板没有实际复用价值。
- 「没取消」是口语残句，不是节点名。
- 「前端参与」含义不明（学员端？管理员端？）。
- 这张图最接近「企业培训运营 SOP」，却是整套里最难被拿走用的一份。

## 5. 共性问题（按严重度）

1. **年代过旧**：全部停在 2018-06-14，八年未更新。当前企业学习场景（多终端、权限、合规、证书、数据权限）基本没有反映。
2. **没有企业 / 业务两层结构**：缺企业级总图（谁能建课、谁能发证、数据归谁），业务图各自为政。
3. **命名不统一**：有的叫「xxx流程图」，有的直接用模块名；图内还残留「普通考试基本流程图」这类草稿标题。
4. **文案质量**：错字（查案直播表）、残句（没取消）、规则文本直接当节点。
5. **模块边界混乱**：考试/阅卷/评审出现在课程、直播、专题多张图里。
6. **异常与权限几乎没有**：取消、失败、越权、过期、补救路径不完整。
7. **复用策略不一致**：培训管理最像企业 SOP，却关闭克隆；高克隆的三张也没有版本说明或适用场景。
8. **经营数据偏弱**：点赞全 0、评论全 0；克隆集中在 3 张图，其余接近沉睡。

## 6. 建议（按优先级）

1. **先补企业层**：单独做 1 张企业模板总图——组织角色、权限、审批、数据归档、证书与合规——再让 7 张业务图引用它，而不是每张图自己写一遍「数据归档」。
2. **把考试合成一套**：PC 考试 + 移动考试抽成「考试业务模板」+「移动端差异」，去掉重复节点。
3. **清边界**：课程 / 直播 / 专题只保留学习过程；考试与评卷只留在考试模板。
4. **打开培训管理克隆，或改成企业 SOP 正式模板**，并修正「没取消」等文案。
5. **统一命名**：对外一律「模块名 + 业务流程图」，对内用同一套泳道（管理员 / 讲师 / 学员 / 系统）。
6. **若正式模板在 Figma**：在 Cursor 桌面登录 Figma 后，按同一检查清单再扫一遍企业页和业务页（组件、Auto Layout、变量、命名、空状态/错误态）。
